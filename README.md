# Prince Aeron D. Montallana – SysAdmin Career Portfolio

Tech stack: HTML5, CSS3, JavaScript (no framework, no database).

## Paano patakbuhin
1. I-extract ang ZIP.
2. Buksan ang folder sa **Visual Studio Code**.
3. I-install ang extension na **Live Server**, tapos right-click `index.html` -> **Open with Live Server**.
   (Pwede ring i-double-click ang `index.html`.)

## Folder structure
```
Montallana_Sysadmin_Portfolio/
├── index.html            (page structure and content)
├── style.css             (design, colors, animations)
├── translations.js       (English / Tagalog text)
├── main.js               (theme, language, effects, code playground)
├── images 014.jpg        (developer portrait used in the hero and About sections)
└── profile.svg           (blue-toned fallback avatar)
```

## Pagpapasadya
- **Pangalan at larawan**: nasa `index.html`; ang kasalukuyang portrait ay `images 014.jpg`.
- **Kulay**: nasa `:root` at `[data-theme="light"]` sa `style.css`.
- **Text sa Tagalog/English**: nasa `translations.js`.
