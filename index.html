Roles and Responsibilities

What a System Administrator does every day to keep systems alive.

💻

Installing & Maintaining Operating Systems

Installs, configures, and updates operating systems like Windows Server and Linux, including patches that fix bugs and security holes.

👥

Managing User Accounts & Permissions

Creates, edits, and removes accounts, and gives each person only the access they need (principle of least privilege).

📈

Monitoring System Performance

Watches CPU, memory, disk, and network usage so problems are caught and fixed before users even notice.

💾

Performing Backups & Recovery

Schedules backups and tests restores so data can be brought back after a crash, mistake, or attack.

🔧

Troubleshooting Hardware & Software

Finds the root cause of errors, slow systems, and failed devices, then fixes them and documents the solution.

🛡

Securing Systems & Networks

Applies firewalls, strong passwords, and security updates to protect the organization's data from threats.

System Administration Tools

Common tools and technologies used by System Administrators.

Windows

Windows Server

Microsoft's server OS for running Active Directory, file sharing, and company services.

Linux

Ubuntu Server

A popular, free Linux server OS used to host websites, databases, and applications.

Shell

PowerShell

A command-line shell and scripting language for automating tasks on Windows systems.

Remote

SSH

Secure Shell lets admins safely log in and control remote servers over an encrypted connection.

Virtual

VirtualBox

Free software to run virtual machines, perfect for practicing installs and testing safely.

Linux

Bash

The standard Linux shell for running commands and writing automation scripts.

Monitor

Task Manager / htop

Shows running processes and live CPU and memory usage to spot slow or stuck programs.

Backup

rsync / Windows Backup

Copies and syncs files to another location so data can be restored when something goes wrong.
